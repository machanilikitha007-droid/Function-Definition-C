# Function Definition in C

This program demonstrates how a function is defined with parameters
and a return value.

## File

function_definition.c

## Concepts Used

- Function definition
- Function parameters
- Return statement
- Function call

## How to Run

gcc function_definition.c -o function_definition
./function_definition
